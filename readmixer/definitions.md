### Helpful definitions for programmers who might not know much about genomics
---

| Term | Definition |
| ----------- | ----------- |
|base|A single DNA nucleotide, represented as A,T,C,G or N in data sets. N represents a base that is unknown.|
|ReadMixer|Name of the software.|
|fastq|FASTQ format is a text-based format for storing both a biological sequence (usually nucleotide sequence) and its corresponding quality scores (the quality score of a read represents its accuracy).|
|ID tag|same as tag.|
|key csv|a "key" file that contains a data table which contains all of the random tags and their corresponding original indexes/tags|
|reads|a read is a single string output from a DNA sequencer that provides information about a string of bases.|
|tag|a piece of DNA (i.e. a string of bases) that can be used to "tag" a piece of DNA from a sample prior to pooling DNA so that the piece of DNA can be attributed to that sample after that pool has been sequenced.|
